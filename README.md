# 💄 Lip Color Explorer (립 컬러 탐색 웹앱)

18~25세 여성 타깃을 고려한 모바일 퍼스트 립 컬러 탐색 및 실발색 확인 웹 애플리케이션입니다.

🔗 **배포 링크:** [https://lip-color-explorer.pages.dev/](https://lip-color-explorer.pages.dev/)

---

## 🛠️ 기술 스택

- **Framework & Language:** React 19, TypeScript
- **Build Tool:** Vite
- **Styling & UI:** Tailwind CSS v4, Lucide React (Icons)
- **Deployment:** Cloudflare Pages

---

## 📌 구현 기능 및 조건 달성 여부

### 1. 필수 구현 사항 (100% 달성)
- [x] **제품 카드 목록:** 각 카드별 이미지, 컬러 스와치(HEX 코드 표시), 브랜드명, 제품명, 컬러명, 제형, 가격 표시
- [x] **제형 필터:** 전체 / 매트 / 글로시 / 벨벳 실시간 카테고리 필터링
- [x] **모바일 레이아웃:** 390px 기준 모바일 뷰포트 최적화 및 데스크톱 반응형 대응

### 2. 선택 구현 사항 (추가 구현)
- [x] **텍스트 검색:** 브랜드명, 제품명, 컬러명, 태그 실시간 통합 검색
- [x] **상세 화면 (Modal & Bottom Sheet):** 카드 탭 시 모바일 바텀시트 / 데스크톱 모달 형태의 상세 화면 제공
- [x] **기타 UX 개선:** HEX 코드 원터치 복사 Toast 알림, 위시리스트(관심 상품) 저장 (localStorage)

---

## 💡 구현하며 가장 신경 쓴 부분

1. **타깃(18~25세) 맞춤 톤앤매너 및 발색 전달력**: 립 컬러 고유의 색상 왜곡을 방지하기 위해 라이트 테마와 은은한 파우더리 베이지 베이스의 캔버스 톤을 채택하여 감성적인 뷰티 앱 느낌과 실발색 명확성을 동시 확보했습니다.
2. **모바일 퍼스트 UX & 세심한 인터랙션**: 390px 기준 한 손 조작(Thumb Zone)이 편리하도록 모바일 바텀시트 상세 화면을 구현하고, HEX 코드 원터치 복사 Toast 및 위시리스트 연동으로 사용자 완성도를 극대화했습니다.
